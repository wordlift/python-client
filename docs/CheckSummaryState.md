# CheckSummaryState

State as stored in monitor_check_summary — a superset of MonitorState that also covers a check currently expected for a monitor but not yet run (see monitor_check_summary_refresh.run_once).

## Enum

* `OK` (value: `'OK'`)

* `WARN` (value: `'WARN'`)

* `FAIL` (value: `'FAIL'`)

* `PENDING` (value: `'pending'`)
